# EternalFishingTraps-PM | [Latest Version](https://github.com/PlanckMosh/PM-EternalFishingTraps/releases/latest/download/EternalFishingTraps-PM.dll)

My very first mod: A way to keep your Fish Traps from breaking in Traveller's rest v0.7.6.12.0

Here's what it should do:
* On loading your save, waking up, and/or loading a zone a fish trap is in:
  * The number of remaining uses is set to **99,999**.
  * The dots showing uses left **disappear**.

With such a high use count being refreshed so often, they're meant to be basically infinite-use.
I didn't see a need to keep the usage dots up, so I tried to find out how to rid of those, too.

I don't think I did that bad of a job, all things considered.

With how the devs aren't as inclined to like *fun* like some of us would, every minor update is
gonna break this mod. I went ahead and made the code for it open enough for you to figure it out
if you wanted to take a crack at making a ver. of it in the future, or if I don't get to it.

Modding this in should be as simple as downloading a release .dll and putting it in your BepInEx's
'plugins' folder. There's no configs because I didn't really see a reason. Don't want it? Remove it :)
